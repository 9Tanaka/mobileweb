SENSOR APP

แอปออกกำลังกายแขน ใช้เซ็นเซอร์ Accelerometer ตรวจจับท่าทาง พร้อมระบบนับครั้ง ตรวจฟอร์ม และ Feedback แบบเรียลไทม์

▶ ดูวิดีโอสาธิต
FEATURES

ฟีเจอร์หลัก

ใช้เซ็นเซอร์ในมือถือร่วมกับ Rule-based Algorithm เพื่อนับและตรวจสอบท่าออกกำลังกายแบบเรียลไทม์

📱

Accelerometer Detection

ใช้ข้อมูลจาก Accelerometer (แกน X, Y, Z) ตรวจจับการเคลื่อนไหวของแขน ผ่าน State Machine สองสถานะ WAIT_UP → WAIT_DOWN

🎯

Form Checking

ตรวจสอบฟอร์ม 4 ด้าน: Range of Motion, ความเร็ว (ไม่เร็ว/ช้าเกินไป), ทิศทางแนวตั้ง และจำนวนครั้งเป้าหมาย 20 ครั้ง

🔊

Text-to-Speech

พูดนับจำนวนครั้งเป็นภาษาไทย และแจ้งเตือนเมื่อฟอร์มไม่ถูกต้อง เช่น "ยกแขนต่ำเกินไป" หรือ "เร็วเกินไป"

📳

Haptic Feedback

สั่นแจ้งเตือนแบบ Success เมื่อทำถูก และ Warning เมื่อฟอร์มผิด ผู้ใช้รับรู้ได้ทันทีโดยไม่ต้องมองหน้าจอ
